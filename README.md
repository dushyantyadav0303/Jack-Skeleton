## About the Project
### **Jack Skeleton** - It is a 3d Printable Halloween theme 3d model of Jack Skeleton holding two Lanterns made in Blender. In which We can use for Halloween decoration.


## why i made this? 
### So I like Halloween and I saw this character from that day i thinking to make my own Jack Skeleton. Which look very good and best for home & workplace.
